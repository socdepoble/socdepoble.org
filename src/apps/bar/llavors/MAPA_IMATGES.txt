MAPA D'IMATGES · La Parròquia · Menjar i Beure (Onada 3, T2, decisió D7)
===========================================================================

Per a qui fa la feina de les fotos (el Mestre o MarIA): els agents no poden
copiar ni convertir binaris.

DESTÍ (arrel del repositori):
  public/assets/uploads/empresa/la-parroquia/bar/<categoria>/<slug>.webp
  És el camí que pinta el Bar (src/apps/bar/vistes/vestits.js, imatgeDe) amb
  l'establiment de slug «la-parroquia». Les línies d'avall diuen
  <categoria>/<slug>.webp, i els slugs són els REALS que genera l'adaptador
  (src/apps/bar/llavors/laParroquia.js).

ORIGEN (relatiu a _wiki_de_poble/04_escriptori/01_produccio/, zona humana):
  loyverse/¡¡¡Imatges de productes/<carpeta>/<fitxer>   el joc principal
  la_parroquia/imatges/<fitxer>                          complement
  Tots els orígens d'este mapa s'han comprovat amb ls el 2026-10-03.

CONVERSIÓ de cada foto:
  1. Retall quadrat 1:1 (Pedra Seca §8), centrat en el producte.
  2. Redimensió a 512 × 512 px.
  3. WebP amb qualitat 75-80: uns 40 KB per foto (orientatiu).
  4. Desa-la al destí, amb el nom exacte (minúscules, guions, .webp).

PAS FINAL (sense este pas, la foto no es mostra):
  a) Afig el slug a IMATGES_DISPONIBLES de src/apps/bar/llavors/laParroquia.js,
     per categoria. Exemple: { cafeteria: ['bombo', 'cafe-sol'], tapes: ['callos'] }
  b) Passa la prova: npx vitest run src/apps/bar/llavors/laParroquia.test.js
     Comprova que cada slug llistat té el seu webp a public/ (una foto marcada
     sense fitxer es veuria trencada: la rajola no té pla B) i que cada destí
     d'este mapa és un slug real i el seu origen existix.
  c) A la tauleta: Ajustos › Carta › «Carrega la carta de La Parròquia» de nou
     (amb el torn tancat), perquè la carta desada agafe les fotos.

AVISOS:
  · Canviar la categoria d'un producte amb foto trenca el camí (la categoria
    forma part del camí).
  · Moltes fotos són envasos de marques baixats de botigues web (els .webloc
    de la_parroquia/imatges ho indiquen): els drets de publicar-les els ha de
    decidir el Mestre abans de fer-ne cap commit (vegeu LLEGIU_PRIMER.txt).
  · El mapatge s'ha fet pel NOM del fitxer, sense mirar les fotos: cal
    revisar-lo a ull. Les marcades «a confirmar» són dubtoses.
