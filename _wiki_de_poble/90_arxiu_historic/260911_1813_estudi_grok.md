## 2. Meta-Anàlisi de Punts Cecs (Grok)

1. **H3: color i tipografia**: Si una IA només llegeix `DesignSectionContent` pot inventar serif o colors genèrics per a títols. La documentació narrativa no repeteix prou "H3 = blau acció, mai serif".
2. **Marges de paràgraf**: La cadena completa de ritme vertical està al CSS, però no hi ha una taula canònica resumida dins de `DesignSectionContent`. Això afavoreix la invenció de marges com 1em o 1.5em.
3. **UniversalCard — DOM exacte**: L'ordre de fills i equivalències de classes (`sp-card-*`) no estan dictades com un diagrama DOM mínim a la guia visual.
4. **Avatars**: Mides i classes s'infereixen de components i CSS, facilitant que les IAs inventen mides de 40px o colors fóra de paleta.
5. **Mode embed de les barres**: Risc d'inventar `sticky` incorrecte perquè el CSS complet de les barres no està resumit.
