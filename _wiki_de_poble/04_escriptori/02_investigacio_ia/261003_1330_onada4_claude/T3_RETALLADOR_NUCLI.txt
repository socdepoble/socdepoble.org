1. API
------
DialegEnquadrament (tot opcional; sense res nou, el contracte T46 és el mateix d'abans)
  · sortida = { ampladaMaxima, format, qualitat }  (null de sèrie)
      format: 'image/webp' de sèrie, també 'image/jpeg' o 'image/png'. Si el navegador no sap
      codificar WebP (toBlob torna un altre tipus), es torna a codificar en JPEG amb fons blanc.
      ampladaMaxima limita l'AMPLADA (mai s'amplia; l'alçada seguix la forma). Sense ella, 1.200.
      Amb `sortida`, el diàleg SEMPRE recodifica: el camí «Original sense zoom torna el mateix File»
      queda només per als pares d'abans (que ja passen per compressImage).
  · permetGeolocalitzacio = false
      true: casella «Vull geolocalitzar aquesta imatge», desmarcada. Marcar-la llig el GPS i la data
      del fitxer ORIGINAL (una vegada per foto), els ensenya en dos camps (latitud, longitud; accepten
      coma decimal), deixa corregir-los o escriure'ls si la foto no en porta, i tria la precisió
      (Exacta 5 decimals / 1 m · Uns 100 m 3 decimals / 100 m · Només el poble 2 decimals / 1.000 m).
      Abans de desar es veu «Es desarà: 38.59, -0.42 (uns 1.000 m).». També força la recodificació.
  · onDesa(fitxer, { format, rect, sencera }, metadades)  ← TERCER argument, sempre present.
      El segon ja existia (info): per això metadades va tercer i no segon, com deia l'encàrrec.
      metadades = { geolocalitzacio: { lat, lng, precisio_m, origen: 'exif'|'manual' } | null,
                    dataCaptura: 'AAAA-MM-DDThh:mm:ss[+hh:mm]' | null }
      Opció apagada (o casella desmarcada): tot null i no s'ha llegit cap GPS.
  · lectorMetadades: injectable per a les proves (de sèrie, llegixMetadadesImatge).
  · Teclat sobre el visor (tabIndex 0, aria-keyshortcuts): fletxes mouen com els lliscadors (Maj, x4),
    + / = i − amplien de 0,1 en 0,1, Retorn desa. Escape continua sent del <dialog>. Una regió
    aria-live (sdp-nomes-lector) anuncia la posició o l'ampliació que fa el teclat.
  · Límits amb avís en línia: més de 25 MB (abans de descodificar), més de 16.384 px per costat o
    50 MP (després, siga quin siga el carregador) i HEIC que no s'obri.

2. DECISIONS
------------
  · Estendre i no duplicar: cap organisme «Retallador» nou (contra RETALLADOR §1, per decisió prèvia).
  · metadades com a tercer argument sempre present: forma uniforme per als pares; els que no el
    volen l'ignoren. Un sol test T46 ha canviat d'expectativa per això (la crida porta 3 arguments).
  · La data de captura també es llig només amb la casella marcada (ADR §3.1: el lector actua quan
    la persona activa l'opció). Amb l'opció apagada, metadades és tot null.
  · Precisió de sèrie «Només el poble» (la més vaga): privacitat de sèrie com D4 i §3.3.
  · dataCaptura: hora local de la càmera en format ISO, amb el sufix d'OffsetTimeOriginal si n'hi ha.
  · El 0/0 es rebutja (receptor sense posició).
  · Fletxes = sentit dels lliscadors (el que s'escolta i el que es fa coincidixen), no el
    d'arrossegar.
  · Mapa: cap capa pròpia al projecte. L'única és l'iframe d'OpenStreetMap del Mur (mapConfig.js),
    servei de tercers: no l'he fet servir (ADR §3.3). Camps numèrics; el mapa queda pendent.
