3. COM APUNTA EL CONTINGUT AL MITJÀ
-----------------------------------
Opció A (recomanada per a esta onada) · Clau natural. La fila de mitjans és ÚNICA per (bucket, ruta), i la
  referència que ja es desa avui ('sdp-media://<bucket>/<ruta>' a profiles.avatar_url i hero_url,
  organizations.logo_url i hero_url, notes.hero_image i logo_image, el src del cos HTML i el payload del Mur)
  la identifica sense ambigüitat. Cap columna nova a les taules de contingut, cap CHECK tocat. La taula és un
  ÍNDEX amb metadades sobre el que ja hi ha.
Opció B (més avant) · Referència per id ('sdp-media://m/<uuid>'). Permetria canviar un mitjà de privat a
  públic MOVENT-lo, sense reescriure cap contingut (resoldria D3-09 sense segona còpia). Però trenca, com a
  mínim:
    - els CHECK de profiles.hero_url (2609261500_identitat_perfil_f1.sql:51-57), organizations.hero_url (:108) i
      organizations.logo_url (:126-129), que exigixen '^(https://|sdp-media://mitjans/|/[^/])';
    - esFontImatgeSegura (src/utils/sanitize.js:110-114), que només admet sdp-media://mitjans/ i mitjans_privats/;
    - el parser de resolveAsset (src/data/supabase/storage.js:134-158), que llig el bucket del primer tram.
  [VERIFICAT: les tres restriccions existixen]. Necessita migració i decisió.


4. ESBÓS SQL (NO ÉS UNA MIGRACIÓ; NO S'HA EXECUTAT)
--------------------------------------------------
Mateix estil que les migracions vigents: transacció amb temps curts, restriccions amb nom, cap escriptura
directa des del client (tot per funció, com el xat: 2609270200_xat_f0_fonament.sql:19), funcions
SECURITY DEFINER amb «set search_path = ''» (tractor-rls), codis d'error propis i «notify pgrst».

begin;
set local lock_timeout = '5s';
set local statement_timeout = '60s';

-- 1 · El mitjà: un fitxer del magatzem (D2) i les seues metadades com a columnes (D6).
--     Clau natural (bucket, ruta): la de la referència 'sdp-media://<bucket>/<ruta>' (§3, opció A).
create table if not exists public.mitjans (
  id                  uuid primary key default gen_random_uuid(),
  tenant_id           uuid not null references public.towns (id) on delete cascade,
  propietari          uuid references auth.users (id) on delete set null,
  bucket              text not null
                      constraint mitjans_bucket_valid check (bucket in ('mitjans', 'mitjans_privats')),
  ruta                text not null
                      constraint mitjans_ruta_valida check (char_length(ruta) between 1 and 512 and ruta !~ '(^/|\.\.|//)'),
  mime                text not null
                      constraint mitjans_mime_valid check (mime in ('image/webp', 'image/jpeg', 'image/png', 'image/avif', 'application/pdf')),
  amplada             integer constraint mitjans_amplada_valida check (amplada between 1 and 16384),
  alcada              integer constraint mitjans_alcada_valida check (alcada between 1 and 16384),
  bytes               integer not null,
  sha256              text not null constraint mitjans_sha256_format check (sha256 ~ '^[0-9a-f]{64}$'),
  us                  text not null default 'general'
                      constraint mitjans_us_valid check (us in ('avatar', 'capcalera', 'logo', 'cos', 'adjunt', 'general')),
  autoria             text constraint mitjans_autoria_llargaria check (char_length(autoria) <= 120),
  -- Els ids de src/components/universal/drets/llicencies.js (cc-by-nc-sa … cc0, lliure, reservats).
  llicencia           text constraint mitjans_llicencia_valida check (llicencia in
                        ('cc-by-nc-sa', 'cc-by-nc-nd', 'cc-by-nc', 'cc-by-nd', 'cc-by-sa', 'cc-by', 'cc0', 'lliure', 'reservats')),
  -- El text de 'lliure' o 'reservats': la mateixa llargària que la columna copyright.
  drets               text constraint mitjans_drets_llargaria check (char_length(drets) <= 256),
  data_captura        timestamptz,
  -- 'cap': sense ubicació; 'poble': només el poble (cap coordenada); '100m' i 'exacta': hi ha fila a
  -- private.mitjans_ubicacio.
  nivell_ubicacio     text not null default 'cap'
                      constraint mitjans_nivell_ubicacio_valid check (nivell_ubicacio in ('cap', 'poble', '100m', 'exacta')),
  ubicacio_publica    boolean not null default false,
  ubicacio_difuminada boolean not null default false,
  -- Derivades SEMPRE per la funció de baix des de la interna: cap client les escriu.
  lat_publica         double precision constraint mitjans_lat_publica_valida check (lat_publica between -90 and 90),
  lng_publica         double precision constraint mitjans_lng_publica_valida check (lng_publica between -180 and 180),
  creat_al            timestamptz not null default now(),
  actualitzat_al      timestamptz not null default now(),
  constraint mitjans_ruta_unica unique (bucket, ruta),
  -- D3 per PROPIETÀRIA i espai (no per poble): vegeu §8, R4.
  constraint mitjans_sha_unic unique (tenant_id, propietari, bucket, sha256),
  -- Els límits reals dels buckets (2609130500:9 i 2609191650:8), no els del client (INVENTARI, L1).
  constraint mitjans_bytes_valid check (
    (bucket = 'mitjans' and bytes between 1 and 5242880)
    or (bucket = 'mitjans_privats' and bytes between 1 and 25242880)),
  -- Format nou tenant/persona/carpeta/fitxer. Un objecte antic de dos trams (persona/fitxer, el que admet
  -- es_ruta_mitjans_publics_propia) no hi cap: si algun dia s'indexen, esta restricció va «not valid».
  constraint mitjans_ruta_del_poble check (split_part(ruta, '/', 1) = tenant_id::text),
  constraint mitjans_coordenades_parell check ((lat_publica is null) = (lng_publica is null)),
  constraint mitjans_coordenades_nomes_publiques check (ubicacio_publica or lat_publica is null)
);

-- 2 · La ubicació interna, fora de l'esquema públic (ADR §3.3). Cap rol de client la llig ni l'escriu.
--     Amb el nivell '100m' ja es desa arrodonida: es guarda el que la persona ha triat, no més (minimització).
create table if not exists private.mitjans_ubicacio (
  mitja_id   uuid primary key references public.mitjans (id) on delete cascade,
  lat        double precision not null constraint mitjans_ubicacio_lat check (lat between -90 and 90),
  lng        double precision not null constraint mitjans_ubicacio_lng check (lng between -180 and 180),
  font       text not null constraint mitjans_ubicacio_font check (font in ('exif', 'manual')),
  creat_al   timestamptz not null default now()
);
revoke all on table private.mitjans_ubicacio from public, anon, authenticated;

alter table public.mitjans enable row level security;
revoke all on table public.mitjans from public, anon, authenticated;
grant select on table public.mitjans to authenticated;
drop policy if exists "mitjans llegir propis" on public.mitjans;
create policy "mitjans llegir propis" on public.mitjans for select to authenticated

-- 4 · Registrar el fitxer que la persona acaba de pujar, o tornar el que ja tenia (D3).
create or replace function public.registra_mitja(
  p_bucket text, p_ruta text, p_mime text, p_bytes integer, p_sha256 text,
  p_amplada integer default null, p_alcada integer default null, p_us text default 'general')
returns setof public.mitjans
language plpgsql volatile security definer set search_path = ''
as $$
declare
  v_jo uuid := (select auth.uid());
  v_tenant uuid;
begin
  if v_jo is null then
    raise exception 'SDP-MITJA-001: cal la sessió iniciada.' using errcode = '42501';
  end if;
  if p_bucket not in ('mitjans', 'mitjans_privats') or p_ruta is null
     or coalesce(p_sha256, '') !~ '^[0-9a-f]{64}$' then
    raise exception 'SDP-MITJA-005: paràmetre invàlid.' using errcode = '22023';
  end if;
  -- La frontera de les polítiques de storage (2609200300:7-17): tenant/persona/carpeta/fitxer i membre del poble.
  if not private.es_ruta_mitjans_propia(p_ruta) then
    raise exception 'SDP-MITJA-003: esta ruta no és teua.' using errcode = '42501';
  end if;
  -- Ruta per contingut (§6): el nom del fitxer, sense extensió, és el sha256.
  if split_part(regexp_replace(p_ruta, '^.*/', ''), '.', 1) <> p_sha256 then
    raise exception 'SDP-MITJA-005: paràmetre invàlid.' using errcode = '22023';
  end if;
  v_tenant := split_part(p_ruta, '/', 1)::uuid;
  -- D3: la persona ja té eixos bytes en eixe espai? Es torna el que hi ha.
  return query select m.* from public.mitjans m
    where m.tenant_id = v_tenant and m.propietari = v_jo and m.bucket = p_bucket and m.sha256 = p_sha256;
  if found then return; end if;
  -- [NO VERIFICAT] Que el propietari de la funció puga llegir storage.objects en el projecte de destí:
  -- l'executor de la baixa ja es protegix d'insufficient_privilege (2609282100:761-762).
  perform 1 from storage.objects o where o.bucket_id = p_bucket and o.name = p_ruta;
  if not found then
    raise exception 'SDP-MITJA-004: el fitxer no és al magatzem.' using errcode = 'P0002';
  end if;
  -- RETURN QUERY amb un CTE: la forma segura de tornar les files d'un INSERT … RETURNING.
  return query
    with nou as (
      insert into public.mitjans (tenant_id, propietari, bucket, ruta, mime, bytes, sha256, amplada, alcada, us)
      values (v_tenant, v_jo, p_bucket, p_ruta, p_mime, p_bytes, p_sha256, p_amplada, p_alcada, coalesce(p_us, 'general'))
      on conflict do nothing
      returning *)
    select * from nou;
  if not found then
    -- Una pujada idèntica en paral·lel ha guanyat: es torna eixa.
    return query select m.* from public.mitjans m
      where m.tenant_id = v_tenant and m.propietari = v_jo and m.bucket = p_bucket and m.sha256 = p_sha256;
  end if;
end;
$$;
revoke execute on function public.registra_mitja(text, text, text, integer, text, integer, integer, text) from public, anon;
grant execute on function public.registra_mitja(text, text, text, integer, text, integer, integer, text) to authenticated;

-- 5 · Llegir les metadades d'un mitjà: una sola porta, per funció i no per política (com perfil_public,
--     2610021520). La propietària ho veu tot; la resta, només d'un fitxer PÚBLIC del seu poble i sense
--     propietari, sha256 ni ubicació interna. «No existix» i «no el pots vore» donen el mateix: cap fila.
create or replace function public.metadades_mitja(p_bucket text, p_ruta text)
returns table (
  id uuid, bucket text, ruta text, mime text, amplada integer, alcada integer, bytes integer,
  sha256 text, autoria text, llicencia text, drets text, data_captura timestamptz,
  nivell_ubicacio text, ubicacio_publica boolean, ubicacio_difuminada boolean,
  lat double precision, lng double precision, es_meu boolean)
language plpgsql stable security definer set search_path = ''
as $$
#variable_conflict use_column
declare v_jo uuid := (select auth.uid());
begin
  if v_jo is null then
    raise exception 'SDP-MITJA-001: cal la sessió iniciada.' using errcode = '42501';
  end if;
  return query
  select m.id, m.bucket, m.ruta, m.mime, m.amplada, m.alcada, m.bytes,
    case when d.meu then m.sha256 end,
    m.autoria, m.llicencia, m.drets,
    case when d.meu then m.data_captura end,                       -- decisió §9, punt 5
    case when d.meu or m.ubicacio_publica then m.nivell_ubicacio else 'cap' end,
    m.ubicacio_publica,
    -- Qui mira ha de saber que la ubicació és aproximada: el difuminat es diu, el punt no.
    case when d.meu or m.ubicacio_publica then m.ubicacio_difuminada end,
    case when d.meu then u.lat when m.ubicacio_publica then m.lat_publica end,
    case when d.meu then u.lng when m.ubicacio_publica then m.lng_publica end,
    d.meu
  from public.mitjans m
  left join private.mitjans_ubicacio u on u.mitja_id = m.id
  -- Un mitjà d'una persona que s'ha donat de baixa (propietari null) no és de ningú: fals, mai null.
  cross join lateral (select coalesce(m.propietari = v_jo, false) as meu) d
  where m.bucket = p_bucket and m.ruta = p_ruta
    and (d.meu or (m.bucket = 'mitjans' and private.is_town_member(m.tenant_id)));
end;
$$;
revoke execute on function public.metadades_mitja(text, text) from public, anon;
grant execute on function public.metadades_mitja(text, text) to authenticated;

-- 6 · Canviar les metadades (mai el binari, D6). Només la propietària. Les coordenades públiques es
--     recalculen sempre des de la interna: una sola font de veritat dins de la fila.
create or replace function public.actualitza_metadades_mitja(p_id uuid, p_canvis jsonb)
returns setof public.mitjans
language plpgsql volatile security definer set search_path = ''
as $$
declare
  v_jo uuid := (select auth.uid());
  v_m public.mitjans%rowtype;
  v_ub jsonb := p_canvis -> 'ubicacio';
  v_nivell text;
  v_lat double precision;
  v_lng double precision;
  v_decimals integer;
begin
  if v_jo is null then
    raise exception 'SDP-MITJA-001: cal la sessió iniciada.' using errcode = '42501';
  end if;
  if p_id is null or jsonb_typeof(coalesce(p_canvis, '{}'::jsonb)) <> 'object' then
    raise exception 'SDP-MITJA-005: paràmetre invàlid.' using errcode = '22023';
  end if;
  select m.* into v_m from public.mitjans m where m.id = p_id for update;
  if not found or v_m.propietari is distinct from v_jo then
    -- La mateixa resposta per a l'absent i per a l'alié.
    raise exception 'SDP-MITJA-006: este mitjà no és teu.' using errcode = '42501';
  end if;
  update public.mitjans m set
    autoria = case when p_canvis ? 'autoria' then nullif(btrim(p_canvis ->> 'autoria'), '') else m.autoria end,
    llicencia = case when p_canvis ? 'llicencia' then nullif(p_canvis ->> 'llicencia', '') else m.llicencia end,
    drets = case when p_canvis ? 'drets' then nullif(btrim(p_canvis ->> 'drets'), '') else m.drets end,
    data_captura = case when p_canvis ? 'dataCaptura' then (p_canvis ->> 'dataCaptura')::timestamptz else m.data_captura end,
    ubicacio_publica = coalesce((p_canvis ->> 'ubicacioPublica')::boolean, m.ubicacio_publica),
    ubicacio_difuminada = coalesce((p_canvis ->> 'ubicacioDifuminada')::boolean, m.ubicacio_difuminada),
    -- Es buiden ací i es recalculen al final: si no, deixar de fer-la pública xocaria amb
    -- mitjans_coordenades_nomes_publiques abans del recàlcul.
    lat_publica = null,
    lng_publica = null,
    actualitzat_al = now()
  where m.id = p_id;
  if p_canvis ? 'ubicacio' then
    delete from private.mitjans_ubicacio where mitja_id = p_id;
    if jsonb_typeof(v_ub) = 'object' then
      v_nivell := v_ub ->> 'nivell';
      if v_nivell is null or v_nivell not in ('poble', '100m', 'exacta') then
        raise exception 'SDP-MITJA-005: paràmetre invàlid.' using errcode = '22023';
      end if;
      if v_nivell <> 'poble' then
        v_lat := (v_ub ->> 'lat')::double precision;
        v_lng := (v_ub ->> 'lng')::double precision;
        if v_nivell = '100m' then
          v_lat := round(v_lat::numeric, 3)::double precision;
          v_lng := round(v_lng::numeric, 3)::double precision;
        end if;
        insert into private.mitjans_ubicacio (mitja_id, lat, lng, font)
          values (p_id, v_lat, v_lng, coalesce(v_ub ->> 'font', 'manual'));
      end if;
      update public.mitjans set nivell_ubicacio = v_nivell where id = p_id;
    else
      update public.mitjans set nivell_ubicacio = 'cap', ubicacio_publica = false where id = p_id;
    end if;
  end if;
  -- Coordenades públiques: cap si no és pública o no n'hi ha; amb «difuminada», 2 decimals (decisió §9,
  -- punt 4); amb '100m', 3; 'exacta' sense difuminar, tal qual.
  select m.* into v_m from public.mitjans m where m.id = p_id;
  select u.lat, u.lng into v_lat, v_lng from private.mitjans_ubicacio u where u.mitja_id = p_id;
  v_decimals := case when v_m.ubicacio_difuminada then 2 when v_m.nivell_ubicacio = '100m' then 3 end;
  update public.mitjans m set
    lat_publica = case when not m.ubicacio_publica or v_lat is null then null
                       when v_decimals is null then v_lat
                       else round(v_lat::numeric, v_decimals)::double precision end,
    lng_publica = case when not m.ubicacio_publica or v_lng is null then null
                       when v_decimals is null then v_lng
                       else round(v_lng::numeric, v_decimals)::double precision end
  where m.id = p_id;
  return query select m.* from public.mitjans m where m.id = p_id;
end;
$$;
revoke execute on function public.actualitza_metadades_mitja(uuid, jsonb) from public, anon;
grant execute on function public.actualitza_metadades_mitja(uuid, jsonb) to authenticated;

notify pgrst, 'reload schema';
commit;

6. EL FLUX D'UNA PUJADA, PAS A PAS
---------------------------------
6.1 Al client (UI, sense Supabase: Model B)
  1. La persona tria el fitxer (File original).
  2. Si ha encés «Vull geolocalitzar aquesta imatge», el lector d'EXIF propi llig el GPS i DateTimeOriginal
     del File ORIGINAL (ArrayBuffer), ABANS del canvas (D5). Mapa per a confirmar o corregir; tria del nivell
     ('exacta', '100m', 'poble'), de la visibilitat i del difuminat.
  3. Canvas: enquadrar i codificar UNA sola vegada (avui són dos: JPEG a 0,92 i WebP a 0,8, INVENTARI L3).
     El blob ix sense EXIF (D4). [NO VERIFICAT que canvas.toBlob no n'escriga mai: per això el guard de 6.3]
  4. port.pujaMitja(blob, { us, privat, amplada, alcada, metadades }).
  5. Es desa mitja.ref al camp de sempre (avatar_url, hero_image, src de la imatge del cos): cap columna
     nova a les taules de contingut (§3, opció A).

6.2 A l'adaptador de Supabase
  1. Sessió i poble com uploadToStorage (src/data/supabase/storage.js:108-115).
  2. sha256 dels bytes del blob amb WebCrypto (context segur; l'ajudant ja existix a
     src/sections/tractors/nucli/canonic.js:154-159 i caldria pujar-lo a src/utils/).
  3. Busca la seua fila per (bucket, sha256) a public.mitjans (la política «mitjans llegir propis» ho deixa):
     si hi és, torna-la amb reutilitzat: true. Cap pujada.
  4. Si no hi és: puja a «<tenant>/<persona>/<carpeta>/<sha256>.<ext>» amb upsert: false. Si el magatzem diu
     que ja existix (una pujada anterior va morir abans del registre), el dona per bo. [NO VERIFICAT el codi
     exacte de l'error de supabase-js per a «ja existix»]
  5. rpc registra_mitja(...) i, si venen metadades, rpc actualitza_metadades_mitja(...).
  6. Torna el Mitja.

6.3 Guard d'EXIF (defensa en profunditat de D4). Una funció pura (proposta: src/utils/portaExif.js) que
  mira els primers 64 KB: JPEG amb un segment APP1 «Exif», o WebP amb un tros «EXIF» al RIFF. Si en porta,
  pujaMitja rebutja amb 'exif'. Proves pures amb bytes fets a mà, sense dependències.

6.4 Per què la ruta per contingut. El servidor no pot comprovar el SHA-256 que declara el client (el magatzem
  no el calcula; [NO VERIFICAT] que Supabase Storage n'expose cap). Amb el sha256 com a nom de fitxer dins de
  la carpeta de la persona, una mentida només fa mal al seu propi espai, i una pujada repetida xoca amb
  upsert: false i es reutilitza. promoteToPublic passa a ser idempotent: la segona promoció troba el públic
  ja fet (INVENTARI, D3-09).

8. RISCOS
---------
R1 · El canvas no és determinista entre navegadors ni versions [NO VERIFICAT]: la mateixa foto tornada a
     processar pot donar altres bytes. La deduplicació caça les pujades, promocions i reenviaments idèntics,
     no «la mateixa foto retallada de nou».
R2 · El sha256 el declara el client (§6.4). La ruta per contingut ho confina; una verificació al servidor
     (Edge Function) seria un altre treball [NO VERIFICAT que convinga ni que hi siga].
R3 · registra_mitja llig storage.objects des d'una funció definidora: pot faltar el permís en el projecte de
     destí (la baixa ja ho preveu, 2609282100:761-762). Si falta, cal un altre camí (p. ex. confiar en la
     frontera de ruta i no comprovar l'objecte).
R4 · L'ADR diu «sha256 únic per tenant». L'esbós el fa únic per PROPIETÀRIA i espai. Únic per poble
     vincularia la meua imatge al fitxer d'una altra persona (si ella es dona de baixa, què passa?) i
     obriria un oracle: pujar una imatge diria si algú del poble ja la té. Decisió.
R5 · contracte.js és SDP-LOCK: el canvi del contracte necessita el procediment del pany.
R6 · Ordre de desplegament: si el client declara la capacitat i la base no té les funcions, cada pujada falla.
     O la migració primer (com perfil_public) o un error honest i la caiguda a 'mitjans'.
R7 · Noms (§2.6).
R8 · Llei del Píxel: cap d'estes peces canvia res de pantalla per si sola. «Les dues» (INVENTARI D3-14 c)
     només la canviaria si el Mestre volguera un sol fitxer per als dos camps; la T3 en curs ja hi puja dos
     obres diferents (la foto sencera i el retall 1:1).
