RESUM
La classe CONTROL de guardes.js només veta U+0000-001F i U+007F. Els controls C1 (U+0085), els caràcters de format (U+00AD,
U+200B-200F, U+202A-202E, U+FEFF) i els separadors U+2028 i U+2029 passen comprovaText, encara que el comentari i el missatge
prometen refusar els salts de línia. A més, un caràcter invisible entre els dígits d'un DNI el partix davant d'identificadorsDe:
la guarda torna [] i en pantalla el número es llig sencer. Importa per a la Finestreta perquè l'àlies del titular i el de
l'expedient són text lliure que es congela, i esta guarda és la que impedix que hi acabe un identificador. Hui no hi ha fuga:
els tres carrils no estan endollats i el Bar passa titular null. Es proposa: CONTROL per propietat Unicode (Cc, Cf, Zl, Zp);
buscar cada forma al text i a una còpia sense invisibles (mai es troba menys que hui); que el missatge diga el que refusa; i
el mateix a la còpia de src/utils/vendes/registreVendes.js, amb una prova de paritat que obliga a tocar els dos fitxers junts.

export function identificadorsDe(text) {
  if (typeof text !== 'string' || text === '') return [];
  const pla = text.replace(/_/g, ' ');
  /* Cada forma es busca dues vegades: al text tal com ve i a una còpia sense
     els caràcters invisibles. Així un invisible no partix cap número, i
     tampoc deixa de fer de vora quan en fa. */
  const senseInvisibles = pla.replace(INVISIBLES, '');
  return FORMES_VETADES.filter(([, patro]) => patro.test(pla) || patro.test(senseInvisibles)).map(([forma]) => forma);
}
