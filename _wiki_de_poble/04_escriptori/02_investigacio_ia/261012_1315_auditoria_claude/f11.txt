RESUM
potImputar, la pregunta prèvia del doble finançament, només comprova que `nova` és un objecte i que els dos imports són cèntims.
No mira `nova.factura` ni `nova.expedient`, encara que el seu JSDoc i el missatge del seu TypeError els nomenen. Sense factura
respon «possible» amb tot l'import disponible; amb una factura que creaExpedient refusaria (ID_INVALID), també; i sense
expedient, o amb un text amb forma d'identificador, l'avís de fons europeus el torna dins d'`expedients`. Per a la Finestreta
és una resposta prèvia que diu «cap» d'una imputació que després no es podrà crear. El carril no està endollat i creaExpedient
continua parant-ho aigües avall: per això queda en baixa. Es proposa exigir esIdOpac als dos ids a la guarda d'entrada, i
dir-ho al JSDoc i al missatge de l'error, que no repetix mai el valor rebut.

/**
 * Si una imputació nova cabria: quant queda disponible de la factura entre
 * tots els expedients i, si no cap, per què. Porta també els avisos que no
 * bloquegen (POSSIBLE_DOBLE_FINANCAMENT_UE). No crea ni canvia res.
 * @param {object[]} expedients
 * @param {{ expedient: string, factura: string, importFactura: number, importImputat: number }} nova
 */
export function potImputar(expedients, nova) {
  if (!Array.isArray(expedients)) throw new TypeError('Cal la llista d’expedients.');
  if (!esObjecte(nova) || !esCentims(nova.importFactura) || !esCentims(nova.importImputat)) {
    throw new TypeError('La imputació nova porta factura, importFactura i importImputat en cèntims enters positius.');
  }
--- NOU ---
/**
 * Si una imputació nova cabria: quant queda disponible de la factura entre
 * tots els expedients i, si no cap, per què. Porta també els avisos que no
 * bloquegen (POSSIBLE_DOBLE_FINANCAMENT_UE). No crea ni canvia res.
 * `expedient` i `factura` són ids opacs, com els que demana creaExpedient:
 * sense ells, o amb un text que no ho és, no es respon (TypeError, sense
 * repetir el valor rebut).
 * @param {object[]} expedients
 * @param {{ expedient: string, factura: string, importFactura: number, importImputat: number }} nova
 */
export function potImputar(expedients, nova) {
  if (!Array.isArray(expedients)) throw new TypeError('Cal la llista d’expedients.');
  if (!esObjecte(nova) || !esIdOpac(nova.expedient) || !esIdOpac(nova.factura) || !esCentims(nova.importFactura) || !esCentims(nova.importImputat)) {
    throw new TypeError('La imputació nova porta expedient i factura (ids opacs) i importFactura i importImputat en cèntims enters positius.');
  }
