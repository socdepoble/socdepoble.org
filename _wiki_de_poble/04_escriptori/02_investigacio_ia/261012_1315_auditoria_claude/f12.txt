RESUM
El comentari de conservacioExpedient promet que, mentre no hi ha justificació, no es dona cap data. El codi no ho complix: amb un
pagament anotat i la justificació buida compara el pagament amb '' (qualsevol data és major), el pren com a base i torna una data
i el text «Es conserva tot l’expedient N anys». En una ajuda amb pagament anticipat eixa data és anterior a la que eixirà quan es
justifique: la Finestreta diria «fins ací» abans d'hora. Hui el dany és baix: cap pantalla crida la funció, `protegit` és sempre
true i el resultat porta «A verificar amb la gestoria.». Es proposa que la base només existisca quan hi ha justificació (el
pagament mana només si és posterior a ella), deixar-ho escrit al comentari i afegir la prova del cicle sencer. Queda una decisió
del Mestre amb la gestoria: si en algun programa el compte ha d'arrancar del pagament, el que es corregix és el comentari.

/**
 * La conservació de l'expedient: fins quan s'han de guardar els papers. Mentre
 * no hi ha justificació no se'n pot dir cap data i és protegit: un pagament
 * anticipat (anterior a la justificació) no fa córrer el compte. És la mateixa
 * lectura prudent del catàleg de documents: sense la data de la justificació,
 * l'ajuda encara és vigent.
 */
export function conservacioExpedient(expedient) {
  const programa = PROGRAMES[expedient.programa];
  const { justificacio, pagament } = expedient.dates;
  const base = justificacio && pagament && pagament > justificacio ? pagament : justificacio;
  return congela({
    fins: base ? sumaMesos(base, programa.conservacioMesos) : null,
    protegit: true,
    text: base
      ? `Es conserva tot l’expedient ${programa.conservacioMesos / 12} anys des de l’última justificació o pagament.`
      : 'L’expedient és viu: no es pot llençar res.',
    verificar: VERIFICAR
  });
}

Taula de la base amb el codi nou (j = justificació, p = pagament):
  j null, p null       → base null → fins null, «L’expedient és viu».
  j null, p amb data   → base null → fins null, «L’expedient és viu». (Hui: base = p.)
  j amb data, p null   → base = j.
  j amb data, p <= j   → base = j.
  j amb data, p > j    → base = p.
Només canvia la segona fila. El text de la branca amb data continua sent cert: quan hi ha base, és l'última de les dues dates.
