# HIGIENE DE L'ESCRIPTORI (TRACTOR COGNITIU)

DESTÍ: .agents/skills/core-higiene-escriptori/SKILL.md (substituïx la versió instal·lada i l'esborrany 260924_0200 del laboratori). S'instal·la amb executor-mutacio i lease, junt amb la porta Olivera v2.

L'eina d'higiene existix i jutja: `tooling/gates/porta-olivera.mjs`. Esta skill diu quan cridar-la, què decidix ella i què has de decidir tu.

## 0. Acte reflex d'obertura

Abans de qualsevol petorreta, pla o auditoria:

```bash
npm run porta:olivera
```

Quatre senyals i quatre destins:

- `❌ N document(s) que ja no viuen ací` → pas 2.
- `❌ Safata d'entrada amb N element(s)` → buida-la: arxiva o classifica cada element (pas 2), mai hi deixes res.
- `❌ Cap Pla d'Implementació de hui` → escriu el pla abans de convocar ningú.
- `❌ Àncores a documents que ja no són a l'Escriptori` → pas 3. Fan caure la porta.

## 1. Criteri: què mor i què es queda

Ho decidix la porta, amb dos rellotges:

- **Jornada** (`ranci`): categoria transitòria i data anterior a hui.
- **Sessió** (`rancisDeSessio`): categoria transitòria, que no siga un pla, amb segell `aammdd_hhmm` anterior al de la petorreta que s'escriu o, si no n'hi ha cap, al del Pla més recent de la taula. Un prompt de les 15:00 és brossa quan s'escriu el de les 15:40, encara que siga del mateix dia.

Categories transitòries: `prompt`, `macro_prompt`, `micro_prompt`, `petorreta`, `auditoria`, `informe`, `bundle`, `macro_bundle`, `micro_bundle`, `pla`, `acta`, `tasques`.

El que decidixes tu:

- **Els plans són la pissarra.** No caduquen per sessió; caduquen per jornada. Un pla pendent d'execució d'ahir el conserves movent-lo tu fora de l'abast de `--arxiva` només si el Mestre ho demana.
- **Una auditoria viu fins que el Pla que la consumix està damunt la taula.** El segell del Pla marca l'aterratge: tot el que hi ha darrere és arxivable.
- **La Safata d'Entrada** (`00_bandeja_d_entrada/`) entra al recompte i ha d'estar sempre buida. `01_produccio` és zona humana i `02_investigacio_ia` és laboratori: ni la porta ni tu les buideu.

## 2. Arxivat: una sola ordre, mai a mà

```bash
node tooling/gates/porta-olivera.mjs --arxiva
```

Mou a `_wiki_de_poble/90_arxiu_historic/` i despenja l'àncora de `00_index_escriptori.md` en el mateix acte. No esborra res; si el destí ja existix, no sobreescriu i t'ho diu. Els documents amb rebut de torn necessiten, a més, `document.mjs handoff --turn-id ID --file ORIGEN --to DESTÍ` perquè el torn no perda el rastre.

## 3. Àncores fantasma

`--arxiva` despenja només les àncores del que mou en eixa passada. Les que ja penjaven d'abans les revises tu a `00_index_escriptori.md`: cada `- [[nom]]` sense `/` que no corresponga a un fitxer viu del primer nivell és un fantasma. Abans de llevar-la, mira on viu el document:

- a l'arxiu → lleva la línia;
- en una subcarpeta de l'Escriptori → reescriu-la amb ruta, `[[02_investigacio_ia/nom]]`;
- a `10_actes/` o una altra carpeta de la Wiki → `[[10_actes/nom]]`, relatiu al vault, perquè Obsidian el resolga.

Esborres l'enllaç, mai el document. Verifica amb `npm run porta:orfandat` i `npm run porta:autosanacio`.

## 4. Les caselles de la secció 0 no són teues

La secció «0. Abans de generar» de tota petorreta porta tres caselles. La porta les contrasta amb el disc: una casella marcada que la comprovació desmentix és un error més greu que una casella buida. Marca-les només després de `npm run porta:olivera` en verd, i entén-les com un resum del que la porta ja ha dit, no com una declaració.

## 5. Ordre innegociable

1. `npm run porta:olivera`
2. Decidir amb el criteri del pas 1.
3. `node tooling/gates/porta-olivera.mjs --arxiva` (i `handoff` per als documents amb rebut).
4. Fantasmes del pas 3.
5. `npm run porta:orfandat`
6. Ara sí: `document.mjs context` i `create` de la petorreta nova. La porta torna a mirar la taula en el `create`.

## Lliçons del Mestre

- **260924 · La sessió la marca el segell, no el dia.** Dos prompts del mateix dia no conviuen a la taula: el segell termodinàmic del nom diu quin és viu.
- **260924 · La Safata d'Entrada és Escriptori.** Tot element dins de `00_bandeja_d_entrada/` compta com a brossa fins que es classifica.
- **260924 · Una casella és un resum de la porta, no una comprovació.** Es marca després del verd, i la porta la contrasta.
- **260924 · L'eina existix; nomena-la.** La higiene es fa amb `porta-olivera.mjs`, que té el criteri codificat; una skill que el descriu amb paraules pròpies condemna a fer-ho a mà.
- **260924 · Arxivar i despenjar l'àncora són un sol acte.** Separar-los fabrica fantasmes que cap eina recull després.
