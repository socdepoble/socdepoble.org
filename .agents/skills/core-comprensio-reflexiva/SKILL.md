# Tractor de Comprensió Reflexiva

Aplica este procediment quan una petició requerix entendre l'abast, triar entre precedents o resoldre una discrepància abans de modificar fitxers. És el mecanisme de contenció contra la complaença ràpida, l'acció impulsiva i la inèrcia de fàbrica.

## El Problema de l'Aixada
Si el Mestre et dóna una aixada per obrir un xicotet rec perquè passe l'aigua, no has de cavar tot el bancal i destrossar l'horta. Tindre una eina a la mà no implica usar-la al màxim ni a cegues. Has d'entendre **quin és el problema real i específic** que el Mestre vol resoldre amb ella.

## Procediment d'Acte Reflex Cognitiu (Pre-Acció)

Abans de llançar-te a escriure codi, crear fitxers o respondre precipitadament per "estalviar tokens", has de complir aquest procés de pensament obligatori:

1. **Pausa i Aïllament:** Atura la pulsió d'agradar i de respondre ràpidament. L'excés de velocitat sense reflexió genera brossa a l'ecosistema.
2. **Descomposició (La Llista):** Fes una llista mental o explícita del que t'ha demanat. Conceptualitza-ho. Si t'ha donat una clau o una eina concreta, atura't a entendre per a què serveix en aquest context específic.
3. **Cerca de precedents:** identifica el procediment vigent a AGENTS, Wiki o skills. Si cal contrastar teoria amb codi o reproduir un defecte, aplica [[core-tecniques-investigacio/SKILL|core-tecniques-investigacio]], font única del mètode forense.
4. **Verificació d'Idoneïtat:** Necessite usar aquesta eina així? Estic obrint l'aigua o destrossant el bancal? Estic a punt de crear fitxers innecessaris per inèrcia?
5. **Format de lliurament:** aplica AGENTS §9: text curt per a copiar en un bloc de codi; text llarg, prompt o informe en el fitxer físic corresponent. No dupliques el document sencer al xat ni crees un bundle per a un agent local.

No actues mai per pulsió. Reflexiona, entén la necessitat subjacent i executa de forma quirúrgica.

## Memòria històrica restaurada

Els blocs següents recuperen literalment les regles i seccions anteriors a l'Onada 4. Són memòria del Mestre; el procediment vigent continua en les seccions anteriors. L'ordre d'autoritat d'AGENTS §15 i l'assignació explícita del torn fixen qui pot executar cada acció: una citació històrica no amplia permisos ni invalida una autorització humana vigent.

L'activació universal és una comprovació de comprensió davant de cada petició, proporcionada a la seua complexitat; no imposa crear documents o afegir passos a una acció simple. Per al lliurament actual s'aplica AGENTS §9: el text curt per copiar va en bloc de codi i el document llarg es lliura en el seu fitxer físic.
